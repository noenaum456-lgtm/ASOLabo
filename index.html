Guía AD e IIS

Administra usuarios y publica sitios en Windows Server

Una guía corta para quien trabaja por primera vez con Active Directory, IIS y escritorio remoto en un servidor compartido.

Aquí encuentras qué hace cada servicio, cómo se conectan entre sí y qué hacer cuando algo falla. Usa el menú para moverte entre secciones.

:: Entrar a tu carpeta y clonar el repositorio
C:\> cd C:\inetpub\wwwroot\grupo\Noe_Ramirez
C:\> git clone https://github.com/usuario/mi-sitio .

:: Comprobar el sitio en el navegador
C:\> start http://localhost/grupo/Noe_Ramirez/

Información básica

Cuatro piezas que debes entender para trabajar en el servidor.

Active Directory (AD)

Es el directorio central donde viven los usuarios, grupos y equipos de una organización. Con él, una sola cuenta sirve para entrar a varios recursos y el administrador controla los permisos desde un solo lugar.

Unidades organizativas y grupos

Una unidad organizativa (UO) es un contenedor que ordena objetos, por ejemplo uno por cada grupo de trabajo. Dentro de ella, un grupo permite dar los mismos permisos a todos sus miembros a la vez.

IIS

Internet Information Services es el servidor web de Windows. Publica las carpetas del sitio, normalmente desde C:\inetpub\wwwroot, y las muestra en http://localhost/.

Escritorio remoto (RDP)

Protocolo que permite usar el servidor como si estuvieras frente a él. Escucha en el puerto 3389 y se abre con mstsc, usando tu usuario y contraseña de AD.

Git y GitHub

Git guarda el historial de tu sitio. Subes el proyecto a GitHub y, desde el servidor, lo descargas con git clone dentro de tu carpeta.

Problemas y soluciones

Abre cada pregunta para ver cómo resolverla.

No puedo conectarme por escritorio remoto

Solución: verifica que la IP y el puerto 3389 sean correctos y que escribas el usuario completo, con el formato DOMINIO\usuario. Confirma que tu cuenta existe y que pertenece al grupo de tu unidad organizativa. Si el error persiste, pide a tu líder que pruebe la cuenta de nuevo.

La contraseña de mi cuenta nueva es rechazada

Solución: AD exige una contraseña compleja: mínimo 8 caracteres con mayúsculas, minúsculas, números y símbolos. Si la cuenta se creó con la opción "El usuario debe cambiar la contraseña al iniciar sesión", define una nueva cuando el sistema la pida.

El navegador muestra error 404 o una lista de archivos

Solución: el archivo index.html debe estar directamente en tu carpeta. Si git clone creó una subcarpeta con el nombre del repositorio, mueve el contenido a tu carpeta o agrega esa subcarpeta a la dirección.

git clone falla

Solución: revisa que la URL esté completa y que el repositorio sea público. Si es privado, el servidor pedirá tus credenciales de GitHub. Asegúrate también de ejecutar el comando dentro de tu carpeta y no en la de otro grupo.

Cambié el sitio y no veo los cambios

Solución: el navegador guarda una copia en caché. Recarga con Ctrl + F5. Si editaste el archivo en GitHub, ejecuta git pull en la carpeta del servidor.
